# Проект "Банковские виджеты"

## Описание:

Проект "Банковские виджеты" - это функционал на Python для вывода информации о банковских операциях пользователю.
В данный момент реализован следующий функционал: маскировка номера карты или счета, сортировка операций по дате
или статусу, получение даты операции в формате "ДД.ММ.ГГГГ", сортировка транзакций по выбранному курсу валют,
вывод описания всех транзакций, генерация номеров карт в указанном диапазоне. В проекте реализован декоратор
с параметрами, который будет автоматически логировать начало и конец выполнения функции, а также ее 
результаты или возникшие ошибки и выводить информацию в файл или консоль. Реализована функция вывода списка транзакций
из json, csv и excel файла, функция конвертации валюты из USD и EUR в рубли. Также реализован файл .env для сокрытия чуствительных
данных. Для функций реализовано логирование.

## Примеры использования функций, декораторов и логирований:

1. Функция *get_mask_card_number* принимает на вход номер карты и возвращает ее маску. Номер карты замаскирован
и отображается в формате XXXX XX** **** XXXX , где X — это цифра номера.

Пример работы функции:
```
7000792289606361     # входной аргумент
7000 79** **** 6361  # выход функции
```

Номер счета замаскирован и отображается в формате **XXXX , где X — это цифра номера.

## Тестирование:
Тестирование было реализовано с помощью библиотеки *pytest*.
Были реализованы тест-кейсы для перечисленных функций в разделе "Примеры использования функций".

#### Модуль masks:

1. Функция *get_mask_card_number*:

   - Тестирование правильности маскирования номера карты.
   - Проверка работы функции на различных входных форматах номеров карт, включая граничные случаи
и нестандартные длины номеров.
   

2. Функция *get_mask_account*:

   - Тестирование правильности маскирования номера счета.
   - Проверка работы функции с различными форматами и длинами номеров счетов.
   - Проверка, что функция корректно обрабатывает входные данные, где номер счета меньше ожидаемой длины.

#### Модуль widget:

1. Функция *mask_account_card*:

    - Тесты для проверки, что функция корректно распознает и применяет нужный тип маскировки в зависимости 
от типа входных данных (карта или счет).
    - Параметризованные тесты с разными типами карт и счетов для проверки универсальности функции.
    - Тестирование функции на обработку некорректных входных данных и проверка ее устойчивости к ошибкам.


2. Функция *get_data*:
    
   - Тестирование правильности преобразования даты.
   - Проверка работы функции на различных входных форматах даты, включая граничные случаи и нестандартные строки 
с датами.
   - Проверка, что функция корректно обрабатывает входные строки, где отсутствует дата.

#### Модуль processing:

1. Функция *filter_by_state*:

    - Тестирование фильтрации списка словарей по заданному статусу state.
    - Проверка работы функции при отсутствии словарей с указанным статусом state в списке.
    - Параметризация тестов для различных возможных значений статуса state.


2. Функция *sort_by_date*:
    
   - Тестирование сортировки списка словарей по датам в порядке убывания и возрастания.
   - Проверка корректности сортировки при одинаковых датах.

#### Модуль generators:

1. Функция *filter_by_currency*:

    - Тестирование корректного вывода транзакций по выбранному курсу валют.
    - Проверка работы функции при отсутствии списка транзакций или выбранного курса валют.


2. Функция *transaction_descriptions*:

    - Тестирование корректного вывода описания всех транзакций.
    - Проверка работы функции при отсутствии списка транзакций.


3. Функция *card_number_generator*:

    - Тестирование корректного вывода номеров карт в заданном диапазоне.
    - Проверка правильного форматирования карт на выходе.
    - Проверка корректного обрабатывания крайних значения диапазона и правильного завершения генерации.

#### Модуль decorators:

1. Декоратор *log*:

    - Тестирование корректного вывода результата в файл или консоль, если нет ошибок.
    - Тестирование корректной обработки разных видов ошибок и вывода сообщения об ошибке в файл или консоль.

#### Модуль utils:

1. Функция *get_transactions_list*:

    - Тестирование корректного возврата списка словарей с данными о финансовых транзакциях из файла json.
    - Тестирование корректного возврата списка словарей с данными о финансовых транзакциях из пустого файла json.
    - Тестирование корректного вывода из файла json, если в файле содержатся данные, отличные от списка.
    - Тестирование корректной обработки ошибок JSONDecodeError и FileNotFoundError.

#### Модуль external_api:

1. Функция *conversion_to_ruble*:

    - Тестирование корректного вывода суммы транзакции, переведенной из валюты(отличной от RUB) в рубли RUB.
    - Тестирование корректной обработку случая, когда status code запроса не равен 200.
